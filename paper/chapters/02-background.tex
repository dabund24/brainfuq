\section{Background}
\label{sec:background}

In this section, we introduce \bfck{} and \qbfck{}, and describe how they can be combined.

\subsection{\bfck{}}
\label{sec:background-bfck}

In \bfck{}, we operate on an, in principle, infinitely sized array of data \cite{brainfuck-esolangs}. Each entry in the array stores a byte, which is zero at every entry before program execution \cite{brainfuck-esolangs}. A \emph{pointer} allows us to modify or read from the data of the memory cell it is pointing at \cite{brainfuck-esolangs}. We summarize all operations \bfck{} provides in \cref{tab:bfck-commands}.

Note that the operations \texttt{+} and \texttt{-} are to be understood modulo 256. For the pointer index, we assume the tape extends in both directions. Hence, negative pointer values are valid. The operations \texttt{[} and \texttt{]} allow us to implement loops. With the operations it provides, \bfck{} is \emph{Turing Complete}, meaning that every computation expressible with languages like C or \textsc{Python} can also be implemented in \bfck{}. \cite{brainfuck-esolangs}
\subsection{\qbfck{}}
\label{sec:background-bfq}

\qbfck{} follows the same principles as \bfck{}, except for the fact that instead of operating on bytes, \qbfck{} works with qubits \cite{brainfuq-esolangs}. In the beginning, all qubits are initialized with the zero state. A qubit the pointer points at can be modified by applying $H$, $X$, and $T$ gates to it, which can optionally be controlled on other qubits with \texttt{\#}. We summarize all operations it provides in \cref{tab:bfq-commands}. Note that our version slightly differs from the version defined in \cite{brainfuq-esolangs}---both in how the operations are defined and in how the qubits are initialized.
Similarly to how \bfck{} is a turing-complete language, a subset of the gates \qbfck{} provides---$H$, $T$, and $\mathit{CX}$ gates---forms a \emph{universal gate set}~\cite{boykin-2000}. With this property, \qbfck{} programs can approximate any quantum state to arbitrary precision.

\subsection{\bfq}
\label{sec:background-hb}

Note that, because \qbfck{} lacks operations such as \texttt{[} and \texttt{]}, it does allow the interpreter to jump to other parts of the program. This motivates the desire to combine \bfck{} and \qbfck{} in a new language---\bfq{}. Here, the operations of each language work on a separate tape.
